# Public disclosure boundary

This repository is an intentionally limited engineering case study.

## Public here

- The product mission and high-level user journeys.
- The system's major components and trust boundaries.
- Generalized engineering decisions and tradeoffs.
- A high-level description of the AI quality pipeline.
- The technologies and engineering disciplines involved.

## Kept private

- Application source code and Git history.
- The assessment question bank and visual assets.
- Exact scoring weights, thresholds, mappings, and prediction parameters.
- Database identifiers, detailed schemas, row counts, and production topology.
- Model prompts, retrieved examples, internal rubrics, and evaluation cases.
- User, educator, and student records.
- Credentials, environment configuration, incident history, and deployment access.
- Commercial plans, partner information, and internal operating procedures.

The diagrams in this repository are explanatory abstractions. They are not a deployable specification of the private system.
